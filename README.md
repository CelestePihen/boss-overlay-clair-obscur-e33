# Boss Overlay for Clair Obscur: Expedition 33

![Updated application screenshot](/screenshot.png)

![Original application screenshot](/img.jpg)

---

This overlay tracks your completion progress in Clair Obscur: Expedition 33 by reading the save file in real time.

It currently supports:
- Bosses
- Pictos
- Monoco feet / skills
- Journals
- Lost Gestrals
- Friendly Nevrons
- Weapons
- Music records
- Current-zone filtering based on the loaded map

The checklist is grouped by zone and can show where missing collectibles are found, including extra metadata such as:
- Recommended zone levels
- Picto nearest flags and acquisition instructions
- Monoco foot drop monsters and known locations
- Journal summaries
- Friendly Nevron resolution state

The application is still under development, so if you encounter any bugs, please report them.

Thanks to [CO E33 Save Editor](https://www.nexusmods.com/clairobscurexpedition33/mods/201) from infarctus for some [code snippets](https://github.com/Infarctus/CO-E33_Save_editor).

Note: Since I saw that no one had made a "Boss Overlay" for COE33 yet, I wanted to try making one, but I wanted to have some quick software to see if it would work. So the project is, for better or worse, vibecoded. I still intend to keep improving the quality of the codebase over time.
